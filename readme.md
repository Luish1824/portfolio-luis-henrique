## 📌 Sobre o Projeto

Este portfólio foi desenvolvido no âmbito do programa **Trilhas Inova**, priorizando uma experiência de utilizador fluida e um design minimalista em modo escuro (`#0d1117`). O site conta com navegação intuitiva por botões em formato de pílula, grelhas auto-organizáveis para os projetos e acesso rápido às redes profissionais.

## 🛠️ Tecnologias e Ferramentas

As seguintes tecnologias foram utilizadas na construção da interface:

* **HTML5**: Estrutura semântica das páginas (`portfolio.html`, `projetos.html`, `certificados.html`, `sobre.html`).
* **CSS3**: Estilização personalizada, Flexbox e CSS Grid (`auto-fit` e `minmax`) para total responsividade.
